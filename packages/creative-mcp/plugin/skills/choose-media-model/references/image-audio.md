# Image, audio and 3D candidates (checked 2026-09-17 to 2026-10-15)

Starting points; confirm with `media_model_schema` and `media_estimate`. Meshy's own API (`meshy:*` text-to-motion, animations, remesh, UV unwrap, retexture with multiview) and Higgsfield Soul are not reachable from Open Herness; use the fal Meshy rows.

## Audio

| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A spoken line                            | ElevenLabs v4 / v4 Turbo / v3 via `kind: "speech"` on the user's ElevenLabs key (see `media_models` defaults); fal copies such as `elevenlabs/tts/eleven-v4`; offline macOS voices for drafts | v4 ≈ 10,000 characters, Turbo half price for drafts, v3 5,000 characters. Full narration workflow: `voiceover-and-sound`.                                                                                                                                               |
| Explicit pauses, pronunciation           | MiniMax Speech 2.8 — `fal-ai/minimax/speech-2.8-hd`, `-turbo`                                                                                                                                 | Pause markup and interjections (see prompting).                                                                                                                                                                                                                                                                                                                                            |
| Songs, beds, structured timing           | Lyria 3.5 — `google/lyria-3.5` (~$0.10 per clip, our runs); Lyria 3 `fal-ai/lyria3` (30 s clips), Pro (≤ 3 min); MiniMax Music 3 — `minimax/music-3`; Eleven Music                            | No Lyria endpoint has a duration field: length and structure go in the prompt, and 3.5 ignored the requested length in our run (62 s for 16 s), so pick a window afterwards. Eleven Music: 3–600 s, `instrumental`, model ids `music_v1`, `music_v2`, `music_v2_5`; $0.15 per minute by the second. |

Stable Audio: 1–190 s (defaults to 190), aimed at instrumental textures, no loop control.                                                                                                                                                                                                                             |
| Transcript with word timing and speakers | Scribe v2 — `fal-ai/elevenlabs/speech-to-text/scribe-v2`                                                                                                                                      | Per-word times, speaker separation, automatic language, audio-event tags and keyterm hints. ## 3D

| Need                                                         | Candidates                                                                                          | What decides it                                                                                                                |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Mesh from a reference or text                                | `fal-ai/trellis-2` (image required); Hunyuan3D 3 — `fal-ai/hunyuan3d-v3/image-to-3d`, `/text-to-3d` | Hunyuan offers geometry-only, low-poly, PBR and multiview options.                                                             |
| Game-ready asset, PBR, face budget                           | Tripo H3.1 — `tripo3d/h3.1/image-to-3d`, `/text-to-3d`; Tripo P2 — `tripo3d/p2/image-to-3d`         | `face_limit`, quad topology (quads may return FBX, not GLB). P2 is low-poly, quads ≤ 25,000 faces.                             |
| Rigged/animated character, clean low-poly or separated parts | Meshy 7.1 — `meshy/v7.1/image-to-3d`, `/text-to-3d`                                                 | Standard, low-poly or smart topology; quad or triangle; PBR; optional humanoid auto-rig with animation presets (animated GLB). |

Bring meshes into Blender (`blender` / `make-3d-scene`) for look-dev and renders.

## Endpoint names

Use the full GPT Image 2.5 operation path (`…/flare/text-to-image`), not the family name. Namespaces vary; don't add `fal-ai/` everywhere.

# Rebuilding product UI as motion

If a scene has to look like a real product's interface:

- Inspect both a visual reference (screenshot/recording) and the current source or live product before rebuilding it. Label which surface and version the reference shows — marketing pages, partner demos and old recordings often show a different UI than today's product.
- Rebuild only the components the shot needs (as EffectCraft layers or HTML), not the whole product.
- Focus attention with crops, zooms and highlights; don't silently delete known controls from a full-UI view.
- All UI text is real text set from the product's copy and fonts; check it against the source at delivery size (`make-product-demo` readability rule).

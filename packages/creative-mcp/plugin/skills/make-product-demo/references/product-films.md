# Polished product films

- Capture stills for the film at the output size (or 2×), never from a downscaled screenshot or a small preview recording.
- Show authentic product states: real data shapes, real copy, the actual current UI (label the version if references differ).
- Structure around one clear transformation: the problem state → the action → the result.
- Motion is composed and deterministic (EffectCraft camera on flat screen layers, eased pans/zooms, highlight boxes, cursor paths); type is real text.
- Revisions are targeted: change the one shot or caption asked about, re-render, and keep earlier takes.
- A physical product in 3D: `make-3d-scene` / `blender` (product shot pitfalls there). Screen recordings composited onto devices inside generated scenes: [screen-inserts.md](screen-inserts.md).
- Recorded scenes: screen recording is macOS-only here; elsewhere use the user's recordings.

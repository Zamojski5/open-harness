# Walkthroughs and tutorials (light production)

- Get clean states, element positions, screenshots or short recordings with the browser tools you have (headless Chrome screenshots at output size; a browser-automation tool if one is connected) instead of building a new automation stack.
- A full-frame shot needs a capture at the output size; a small window recording can't be enlarged without losing text.
- On macOS, record with `screen-capture`; elsewhere ask for the user's own recordings.
- Desktop apps: set them up by their own means (files, settings, CLI); show a visible pointer only when it helps the viewer follow.
- Narration can be live (recorded with the take) or separate (written to the cut, `voiceover-and-sound`); burned-in captions for social by default.

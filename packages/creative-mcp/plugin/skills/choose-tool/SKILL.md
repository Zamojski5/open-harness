# Choose the tool

## 1. Check what exists (fast, no installs)

```bash
ls -d /Applications/*.app /Applications/*/*.app ~/Applications/*.app 2>/dev/null | grep -i -E 'blender|effectcraft|krita|gimp|inkscape|audacity|resolve|kdenlive|godot|obs|comfy|chrome|chromium|brave|edge|after effects|premiere|photoshop|illustrator|final cut|capcut|descript|cinema 4d|houdini|reaper|ableton|figma'
command -v ffmpeg melt inkscape gimp godot node npx python3 uv manim comfy brew 2>/dev/null
ls -d /Applications/Houdini/*/ "/Applications/Maxon Cinema 4D"*/c4dpy.app 2>/dev/null   # hython / c4dpy
```

Also `blender_status`, `media_models` (empty/failed = no AI keys), and whether Figma or PixelLab MCP tools are in this session.

## 2. Decide by outcome

**Is 3D actually needed?** Use Blender only when it adds something the other routes cannot: (a) a physical product whose exact geometry, materials or logo must stay true across shots; (b) camera and light control over several shots, or a previs that render-to-real will finish; (c) the 3D itself is the point (turntable, product animation, an abstract brand world). For people-led brands, services, apps and photo-style campaigns, start from real or generated photography composited in PhotoCraft/LightCraft and motion in EffectCraft; a phone mockup comes from a photo or a template, not a Blender scene. Say in one line why 3D is or isn't used.

When the user **names an app** they already work in (Premiere, Final Cut, Photoshop, After Effects, Ableton…), deliver into that app via its skill even if another tool would be our first choice. Each app skill has a "Gaps" section — tell the user up front when a step needs their hands.

Tie-breakers: prefer (1) what's already installed, (2) local and free over paid APIs, (3) tools with a live view the user can watch (Blender, EffectCraft) for creative work, (4) re-renderable sources (HTML, .blend, .ecproj) over one-off pixels.

## 3. When the best app is missing

1. Say which app would be better and why in one line, and what you can do right now with installed tools.
2. **Ask before installing. Never install silently.** Offer the exact command, e.g. `brew install --cask inkscape` (also: `krita`, `gimp`, `audacity`, `kdenlive`, `godot`, `obs`, `blender`, `reaper`); per project via npm/pip: `remotion`, `hyperframes`, `manim` (venv/`uv`). Manual downloads or subscriptions: DaVinci Resolve (blackmagicdesign.com — not the sandboxed App Store build), ComfyUI Desktop, Adobe apps, Final Cut Pro, Cinema 4D, Houdini, Ableton Live, CapCut, Descript. Mention size/time if large.
3. If Homebrew is missing (`command -v brew`), point to https://brew.sh instead of installing it yourself.
4. Without consent, continue with the fallback (HTML/SVG, ffmpeg, Blender, EffectCraft are available here).
5. Prefer open-source suggestions; say when an app is proprietary (DaVinci Resolve is freeware/paid Studio; Adobe, Apple, Maxon, SideFX, Ableton, Cockos, ByteDance and Descript apps are commercial; Remotion needs a company licence above small-team size).

## 4. Hand off

Load the chosen outcome/app skill and follow its workflow — including the quality loop (references → small steps with screenshots → compare → takes → honest review).

# Contributing

Open Harness is built by a small team. Setup, commands and rules for humans and coding agents are in [AGENTS.md](AGENTS.md).

## Workflow

1. Branch from `main` (`feat/...`, `fix/...`). Never push to `main` directly.
2. Keep one change per pull request. Say what problem it solves and how you checked it.
3. Run `vp run check:changed` before pushing. UI changes need before/after screenshots.
4. Another maintainer reviews and merges.

## Never commit

Client names or material, API keys, personal paths or emails, local databases, recordings, renders. Example data uses fictional brands.
